Hello, Dear Reader! Welcome to my first blog post, I wonder what I can write here...

I've been recently getting into Rust, The Programming Language (btw). And after making 3 decent-sized projects with it, I feel like I'm starting to get the hype about it! It is so nice to have a strongly typed language with a lot of [syntactic sugar](https://en.wikipedia.org/wiki/Syntactic_sugar) that Rust provides. Moreover the ample amount of documentation and community support it is so easy to start developing any systems-level software. I also quite enjoy the fact that you can use other people's crates as a part of your code.

The last point particularly resonates with me as an avid NixOS user that I am. I feel like being able to first use a declarative development environment (courtesy of [nix shell](https://nix.dev/manual/nix/2.35/command-ref/nix-shell.html)) and later use that devenv and build a project deterministically... Eelco Dolstra would be proud of me for sure!

The only logical step after using Rust and Nix is to now declaratively get my life together but alas the technology has not yet advanced that far. So my only alternative is to somehow survive in this brutal imperative world. Despite the all-consuming emptiness inside my soul after that realisation, I still have a glimer of hope in the form of different project ideas that Rust might be perfect for! I've been meaning to build a Game Boy Advance emulator and I feel like it might be fun to code it in a language that I barely know.
